Doom, rendered by Logfire

rendering the first frame

W/S move, A/D strafe, Q/E or arrows turn, Shift runs. Every frame is one 69 KB SQL query to Logfire's /v2/query, over a map stored as 90,692 spans. No collision, no monsters moving: it is a renderer.

Source (GPL-2.0), based on SQLDoom and SailDoom, with data from Freedoom.
